### 📸 [Crack Detection System](https://github.com/chiyeon01/Crack_Detection_System)
`Arduino` `IOT COSS` `FastAPI` `PyTorch` `YOLO` 

A **road-condition management system** that first estimates impact magnitude via sensors to detect fine cracks in the road, then uses GPS and a segmentation model to determine the crack's condition and display it on a map.

- Collects 0.1 seconds of data from the accelerometer, calculates the impact magnitude, and processes it against a threshold
- When an impact above a certain level is detected, the impact magnitude is stored together with the GPS data via IOT COSS and sent to the FastAPI server
- On the FastAPI server, a real-time camera feed is analyzed with a segmentation model to determine whether the impact was really caused by a crack, then the result is displayed and saved via the UI
